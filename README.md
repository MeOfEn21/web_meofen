## General info
This project is created to listing all modern movies from multi-sources. You can find one of them which you really perfer to watch.
	
## Technologies
Project is created with:
* Vite version: 5.4.8
* React version: 18.3.1
* react-router-dom version: 6.26.2
* nodejs version: 20.16.0
	
## Setup
To run this project, install it locally using npm and git:
### step1: Cloning Project

```bash
$git clone https://github.com/MeOfEn21/web_meofen.git
$cd web_meoften
```
### step2: Run Project
```bash
$npm install
$npm run dev

```
If everything go well, navigate to your browser on port 3000 or any routes list in your terminal =>  http://locahost:3000

Demo website : [@MeOfen](https://meofen.vercel.app)
